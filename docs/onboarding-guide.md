# Build Your Tank：新手指引与申请 demo

## 项目理解

项目把「搭建水族箱」作为连接设计、学习和日常实践的入口。用户可以创建多个独立鱼缸，在固定家具比例的房间里比较尺寸；了解鱼、植物和设备后进行选购；探索水环境设置，通过签到和照料形成日常习惯；最后保存作品并分享快照。申请 demo 的主线是 **从一个新手的想法，到一个可以理解、照料和分享的小生态系统**。

当前实现是 React + Vite 的浏览器本地原型。昵称和访客登录进入同一个本地工作区；当前没有身份验证、云存档或实时社区。模型中的水质、负载和 30 天结果是简化学习估计。旁白如实描述这些已实现能力，避免把未来规划说成已有功能。

## 使用指引

1. 从首页点击 **Build your first tank**，输入昵称或选择访客入口。
2. 第一次进入会显示欢迎指引，点击 **Start my guide** 开始。也可以选择 **Explore on my own**。
3. 每一步都包括功能说明、操作建议，以及打开功能的按钮。步骤切换会进入对应页面；打开功能按钮会打开实际弹窗或滚动并突出对应区域。
4. 用户自行购买、配置和照料。**Next step** 只记录这一步已经阅读，不表示系统验证了操作完成。
5. 下拉列表允许随时跳到任何一步；**Back** 回看，**Pause guide** 暂停。顶部 **Guide** 可以继续或在完成后重新开始。
6. **Show recording script** 展示当前步骤的英文旁白和中文镜头说明。录制时可以收起，保持产品画面简洁。

刷新会保留阅读进度和当前步骤。主页、登录页及只读分享页隐藏操作指引。首次自动提示只发生在登录入口之后，普通页面跳转不重复弹出。跳到最后一步不会将前面的步骤标为已读，完成前会返回尚未阅读的步骤。

## 调整顺序、内容和旁白

**直接在产品里编辑：** 顶部 Guide → **Edit guide & demo script**，或指引面板 → **Edit guide & script**。

- 左侧每一步的 ↑ / ↓ 调整顺序，步骤 ID 不变，阅读进度按 ID 保留。
- 右侧修改标题、简介、逐行操作说明、实际功能入口、英文旁白、中文录制说明和镜头秒数。
- 顶部折叠区域修改整个 guide 的名称，以及 demo 开场与结尾旁白/时长。
- **Save guide & script** 保存到当前浏览器。**Cancel** 放弃本次草稿。
- **Export script** 导出带累计时间码的 Markdown 录制脚本，也显示可直接选择复制的文本，供下载受限的浏览器使用。
- **Export JSON** 导出完整可编辑配置；**Import JSON** 导入后检查，再保存。
- **Reset draft to default** 仅恢复编辑草稿，点击 Save 后才应用。不会删除鱼缸、余额、物资或照料记录。

**修改项目默认版本：** 编辑 `src/content/guide.json`，`steps` 数组顺序就是引导顺序。将产品里导出的 JSON 替换此文件，可让新浏览器使用修订版。已经保存本地配置的浏览器需要在编辑器导入新版，或恢复默认草稿再保存。

生成默认录制文档：

```sh
npm run guide:script
# 或
node scripts/export-guide-script.mjs
```

输出为 `docs/demo-script.md`。直接编辑这个 Markdown 可以调整你的录制稿，但不会回写产品中的 guide；要保持两者同步，应修改 JSON 或产品编辑器后再导出。文案配置不包含可执行代码或任意网页地址，功能入口只能选择当前应用支持的目标。

## 录制方案

默认计划 **3 分 55 秒**，英文旁白约 446 词，包含开场、12 个功能镜头和结尾。时间码是镜头规划，不是强制计时；实际操作可先录制，再剪辑并配音。

作品贯穿主线：**Quiet Garden → 60cm → 普通玻璃 → ADA Aqua Soil Amazonia → 海绵过滤 → 单只 Betta → Anubias Kirin 和 Rotala 各一株**。该组合用于展示原型操作，真实水族箱仍需要完整的建缸、循环和物种护理准备。

1. 使用独立浏览器配置或独立演示会话，保留原有作品。以干净工作区开始，默认可用余额为 300 demo coins，已带有基础照料物资。
2. 先录制首页和登录入口，开场配音表达项目目标。开始 guide 后收起录制稿，保持画面简洁。
3. 按默认步骤使用同一个新建鱼缸。Tank idea 只查看；示例副本不是主线的必要操作。
4. 在商店核对 **Shopping for** 为 Quiet Garden。添加一只 Betta、两株植物，不往默认混养示例中继续添加。
5. 演示温度警告后恢复 25°C。完整展示喂食、换水和施肥的资源消耗与完成状态。
6. 每个照料动作每缸每日只可用一次。重录可以建立新的演示鱼缸；签到已经领取时展示已领取状态即可。
7. 保存后展示快照分享。另一个标签可以打开快照验证只读行为；不要把本地画廊开关描述为线上发布。
8. 最后展示 guide 编辑入口，说明内容与顺序可以迭代，再以产品目标和诚实的下一步规划结束。

提交版录制应使用实际可访问的托管地址。`127.0.0.1` 分享链接只能在运行本地服务的电脑打开。此修改没有发布网站、提交申请或上传视频。

## 维护与验收

- `src/content/guide.json`：默认步骤、操作说明、旁白、镜头说明。
- `src/components/Guide.jsx` / `src/guide.css`：欢迎、进行中的指引、编辑器和录制稿显示。
- `src/lib/guide.js`：配置校验、阅读进度、步骤重排和脚本导出。
- `src/lib/guide.test.js`：配置和存储容错、ID 保留、跳步与完成、脚本同步与时间码。
- `scripts/check-guide-render.mjs`：静态渲染检查，不替代浏览器交互或视觉验收。
- 本地存储键 `buildyourtank:guide:config:v1` 和 `buildyourtank:guide:progress:v1` 与工作区数据独立。

验证命令：

```sh
npm test
npm run build
node scripts/check-guide-render.mjs
```

本轮浏览器验收已覆盖：昵称首次进入的欢迎指引、访客返回、12 步顺序推进和跨页操作、新建与配置 Quiet Garden、百科群组和词条返回、真实选购、观察缩放、定位后返回指引、三种日常照料、预览、保存和分享弹窗、完整阅读后重开、跳步后返回未读内容、刷新恢复、暂停和继续、编辑重排与旁白保存、JSON 导入、JSON/Markdown 导出文本、Escape 关闭，以及桌面和 390px 视口的布局。浏览器控制台未发现运行时错误。

浏览器最初访问因自动审批服务容量不足被拦截，在用户允许重试后恢复。验收工具未捕获到下载文件的完成回执，因此不把实际文件落盘标为已验证；两种导出都提供已验收的可复制文本，仓库中也保留完整脚本文档。
